# 💰 Expense Tracker

A simple and responsive Expense Tracker built using HTML, CSS, and JavaScript. Track your daily expenses, calculate total spending, and manage expenses through an easy-to-use interface.

## ✨ Features

- ➕ Add expenses with name, amount, and category
- 🧮 Automatically calculate total expenses
- 🗑️ Delete individual expenses
- 🔄 Automatically reset the form after adding an expense
- 📱 Responsive layout for different screen sizes

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript (DOM Manipulation and Event Handling)

## 🚀 Getting Started

1. Clone the repository:

   ```bash
   git clone https://github.com/sweaditya/expense-tracker.git
   ```

2. Open the project folder:

   ```bash
   cd expense-tracker
   ```

3. Open `index.html` in your browser, or use the Live Server extension in VS Code.
